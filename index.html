SQL Quick Guide

SQL é uma linguagem para consultar e manipular dados em tabelas.

  • SELECT: escolhe colunas.
  • FROM: indica a tabela.
  • WHERE: filtra registros.
  • ORDER BY: ordena resultados.
  • GROUP BY: agrupa registros.
  • JOIN: combina tabelas relacionadas.
  • INSERT, UPDATE, DELETE: alteram dados.

Complete as lacunas no editor e selecione Run Query. Use as dicas gradualmente. Tentativas são ilimitadas.
